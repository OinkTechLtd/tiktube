FAQ

Ответы на самые частые вопросы

Видео и воспроизведение
Почему чёрный экран при воспроизведении?
YouTube блокирует встраивание на незнакомых доменах. TikTube использует несколько прокси-серверов и автоматически переключается между ними. Нажми кнопку 🔄 «Прокси» на видео — плеер перезагрузится с другим сервером. Если все не работают — жми «Открыть на YouTube».
Видео грузится, но не играет
Убедись что: 1) Ты нажал на кнопку ▶ в центре; 2) Звук не заблокирован браузером (нажми на иконку 🔇 в адресной строке); 3) Попробуй нажать 🔄 чтобы сменить прокси-сервер.
Можно смотреть видео без YouTube API ключа?
Да — если у тебя есть прямая ссылка вида tiktube.site/?v=VIDEO_ID. Видео откроется без ключа. Ключ нужен только для поиска и загрузки трендов.
Как переключить прокси если видео не работает?
Нажми кнопку 🔄 «Прокси» на боковой панели видео или в нижней полоске. Приложение автоматически попробует следующий прокси-сервер из списка. Всего их 4 штуки.
YouTube API ключ
Зачем нужен API ключ?
Для поиска видео и загрузки трендов приложение обращается к YouTube Data API v3. Google требует ключ для авторизации запросов. Ключ полностью бесплатный.
Как получить API ключ?
Читай подробный туториал с иллюстрациями. Кратко: зайди на console.cloud.google.com, создай проект, включи YouTube Data API v3, создай API key.
API ключ реально бесплатный?
Да. YouTube Data API v3 бесплатный до 10 000 единиц в день. Карта не нужна. Поиск стоит 100 единиц, загрузка видео — 1 единицу. Для личного использования хватает с запасом.
Ошибка "API key not valid"
Проверь: 1) Ключ скопирован без лишних пробелов; 2) В проекте включён именно YouTube Data API v3; 3) Ключ не ограничен по IP/домену (убери ограничения или добавь нужный домен).
Ошибка 403 quotaExceeded
Превышена дневная квота. Подожди до следующего дня (сброс ~12:00 МСК). Или создай второй проект в Google Cloud и новый ключ.
Шаринг и ссылки
Как поделиться видео с другом?
Нажми 🔗 «Поделиться» на боковой панели или в нижней полоске. Скопируй ссылку — она выглядит так: tiktube.site/?v=dQw4w9WgXcQ. Друг откроет видео сразу, даже без API ключа.
Ссылка у меня и у друга ведёт на разные видео?
Такого быть не должно — ссылка привязана к конкретному VIDEO_ID из YouTube. Убедись что копируешь полную ссылку с параметром ?v=....
Технические вопросы
Приложение сохраняет мои данные?
API ключ и лайки сохраняются только в твоём браузере (localStorage). На сервер ничего не отправляется. Читай нашу Политику конфиденциальности.
Работает ли на мобильном?
Да, приложение оптимизировано для мобильных. Листай видео свайпом вверх/вниз — как TikTok. Работает в Chrome, Safari, Firefox на iOS и Android.
TikTube не связан с YouTube/Google?
Верно. TikTube — независимый проект с открытым кодом. Он использует публичный YouTube Data API v3 по правилам Google. Мы не являемся аффилиатами YouTube или Google.
