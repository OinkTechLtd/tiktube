Условия использования

Последнее обновление: январь 2025 г.

Используя TikTube, ты принимаешь эти условия. Пожалуйста, прочитай их.

1. О сервисе

TikTube — некоммерческий проект с открытым исходным кодом. Это клиентское приложение, которое использует публичный YouTube Data API v3 для отображения контента из YouTube.

⚠️ TikTube не является официальным продуктом YouTube или Google. Контент принадлежит его правообладателям.

2. Использование YouTube API

TikTube использует YouTube Data API v3 в соответствии с условиями использования API-сервисов YouTube. Используя TikTube, ты также соглашаешься с:

  • Условиями использования YouTube
  • Политикой конфиденциальности Google

3. Интеллектуальная собственность

Весь видеоконтент, отображаемый в TikTube, принадлежит YouTube и соответствующим правообладателям. TikTube не хранит, не воспроизводит и не копирует видеофайлы — только встраивает официальный YouTube-плеер.

4. Запрещено

  • Использовать TikTube для скачивания контента с нарушением авторских прав
  • Использовать в коммерческих целях без разрешения
  • Распространять вредоносные модификации кода

5. Отказ от ответственности

TikTube предоставляется «как есть» без каких-либо гарантий. Мы не несём ответственности за:

  • Недоступность прокси-серверов или YouTube API
  • Изменения в политике YouTube, которые могут повлиять на работу приложения
  • Любые убытки, возникшие в результате использования сервиса

6. Открытый код

Исходный код TikTube распространяется под лицензией MIT. Ты можешь свободно использовать, модифицировать и распространять его с указанием авторства.

Мы можем изменять эти условия. Актуальная версия всегда доступна на этой странице.
