Политика конфиденциальности

Последнее обновление: январь 2025 г.

🔒 Коротко: мы не собираем никаких личных данных. Всё хранится только на твоём устройстве.

1. Какие данные мы собираем

TikTube не собирает и не хранит никаких персональных данных пользователей на серверах. Всё хранится исключительно в локальном хранилище твоего браузера (localStorage):

  • YouTube API ключ (введённый тобой)
  • Список лайкнутых видео

Эти данные никогда не покидают твоё устройство.

2. Сторонние сервисы

TikTube использует следующие сторонние сервисы:

  • YouTube Data API v3 (Google) — для поиска видео и загрузки метаданных. Твои запросы к API регулируются Политикой конфиденциальности Google.
  • Прокси-серверы — для воспроизведения видео. Они работают как промежуточный слой между тобой и YouTube. Мы не контролируем логирование этих серверов.
  • Google Fonts — для загрузки шрифтов. Google может записывать IP-адреса при запросах к CDN.

3. Cookies и трекинг

TikTube не использует cookies, аналитику, счётчики, пиксели отслеживания или любые другие инструменты трекинга.

4. Реклама

TikTube не показывает рекламу и не монетизирует пользовательские данные.

5. Дети

TikTube не предназначен для детей до 13 лет. Мы не собираем данные детей намеренно.

6. Как удалить свои данные

Открой настройки браузера → очисти данные сайта (localStorage). Или в консоли браузера:

localStorage.clear()

7. Изменения политики

Мы можем обновлять эту политику. Об изменениях будет сообщено на сайте. Продолжение использования сервиса означает согласие с новой редакцией.

8. Контакт

Вопросы по конфиденциальности: создай Issue на GitHub.
