Как получить YouTube API ключ

Подробный туториал шаг за шагом — от регистрации до работающего ключа. Занимает ~5 минут, ключ бесплатный.

Содержание

Шаг 1 — Зайти в Google Cloud Console Шаг 2 — Создать проект Шаг 3 — Включить YouTube Data API v3 Шаг 4 — Создать API ключ Шаг 5 — Вставить ключ в TikTube Лимиты и квоты Частые вопросы
ШАГ 1

Зайти в Google Cloud Console

Открой ссылку в браузере:

https://console.cloud.google.com/

Войди в аккаунт Google (или создай — это бесплатно). Если видишь предложение принять условия использования — принимай.

Аккаунт Google нужен любой — можно использовать личную почту @gmail.com
ШАГ 2

Создать новый проект

В левом верхнем углу нажми на название проекта (или кнопку "Select a project"). Откроется попап.

  • 1

    Нажми "NEW PROJECT" (в правом верхнем углу попапа)

  • 2

    В поле Project name введи любое название, например: tiktube-app

  • 3

    Нажми "CREATE" и подожди пару секунд пока проект создастся

  • 4

    Убедись что ты выбрал только что созданный проект (проверь в левом верхнем углу)

Название проекта не важно — только ты его видишь
ШАГ 3

Включить YouTube Data API v3

Теперь нужно активировать нужный API для этого проекта.

  • 1

    В левом меню нажми "APIs & Services" → "Library"

  • 2

    В поиске напиши: YouTube Data API v3

  • 3

    Кликни на результат "YouTube Data API v3"

  • 4

    Нажми большую синюю кнопку "ENABLE"

  • 5

    Подожди несколько секунд пока API активируется

Обязательно убедись что выбрал именно YouTube Data API v3, а не другой YouTube API
ШАГ 4

Создать API ключ

После активации API нужно создать сам ключ доступа.

  • 1

    В левом меню нажми "APIs & Services" → "Credentials"

  • 2

    Нажми "+ CREATE CREDENTIALS" вверху страницы

  • 3

    Выбери "API key" из выпадающего списка

  • 4

    Ключ создастся автоматически — появится попап с ключом

  • 5

    Скопируй ключ — он выглядит примерно так:

AIzaSyD-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Нажми кнопку "RESTRICT KEY" чтобы ограничить ключ только YouTube API — это повысит безопасность (необязательно, но рекомендуется)

Если хочешь ограничить ключ (рекомендуется):

  • A

    В разделе "API restrictions" выбери "Restrict key"

  • B

    Из списка выбери "YouTube Data API v3"

  • C

    Нажми "SAVE"

ШАГ 5

Вставить ключ в TikTube

  • 1

    Вернись на главную страницу TikTube

  • 2

    Нажми кнопку ⚙️ (настройки) в правом верхнем углу

  • 3

    Вставь скопированный ключ в поле ввода

  • 4

    Нажми "Сохранить"

  • 5

    Готово! Видео начнут загружаться 🎉

Ключ сохраняется в браузере — вводить его каждый раз не нужно
ЛИМИТЫ

Квоты и ограничения (бесплатно)

YouTube API бесплатный, но у него есть дневные лимиты:

Бесплатная квота: 10 000 единиц / день Стоимость запросов: • Поиск (search) = 100 единиц • Видео (videos) = 1 единица • Каналы (channels) = 1 единица Пример: 10 000 / 100 = 100 поисков в день (бесплатно)
Для личного использования квоты более чем достаточно. Сброс происходит каждый день в полночь по тихоокеанскому времени (Лос-Анджелес).
Если превысишь квоту — появится ошибка 403. Просто подожди до следующего дня или запроси увеличение квоты в Google Cloud Console.
FAQ

Частые вопросы

❓ API ключ бесплатный?
Да, полностью бесплатный до исчерпания дневной квоты в 10 000 единиц. Карта не нужна.
❓ Нужна кредитная карта?
Нет. YouTube Data API v3 не требует платёжных данных. Регистрируйся только с Google-аккаунтом.
❓ Ошибка "API key not valid"
Убедись что: 1) Ключ скопирован без лишних пробелов, 2) Для проекта включён YouTube Data API v3, 3) Ключ не ограничен по IP или доменам неправильно.
❓ Ошибка 403 quotaExceeded
Исчерпана дневная квота. Подожди до следующего дня (сброс в ~12:00 по МСК). Или создай второй проект с новым ключом.
❓ Почему видео не воспроизводится?
Это не зависит от API ключа. Нажми кнопку 🔄 (Прокси) на видео чтобы переключиться на другой прокси-сервер. Если все прокси не работают — попробуй позже.
❓ Можно ли поделиться ключом с другом?
Технически можно, но не рекомендуется — вы будете расходовать общую квоту. Лучше каждый создаёт свой ключ — это быстро и бесплатно.
❓ Видео не загружаются вообще без API ключа?
Если кто-то поделился с тобой ссылкой на конкретное видео (с параметром ?v=...) — оно откроется и без API ключа. Ключ нужен только для поиска и загрузки трендов.
