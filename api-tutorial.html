Шаг 1

Открыть Google Cloud Console

Зайди по этой ссылке в браузере — лучше в Chrome или Firefox:

https://console.cloud.google.com/
console.cloud.google.com

Войти в аккаунт Google Создать аккаунт
Аккаунт Google полностью бесплатный. Можно использовать любую почту @gmail.com. Кредитная карта не нужна.

После входа ты увидишь главную панель Google Cloud. Не пугайся — нам нужно только пара кликов.

Шаг 2

Создать проект

В Google Cloud всё организовано через «проекты». Нам нужен один новый проект для нашего ключа.

console.cloud.google.com  |  Google Cloud Console
☰ Google Cloud 📁 Мой проект ▾ ← нажать сюда
Кнопка выбора проекта — в левом верхнем углу
  • 1
    Нажми на название проекта в левом верхнем углу (рядом с лого Google Cloud). Откроется попап со списком проектов.
  • 2
    В правом верхнем углу попапа нажми кнопку «NEW PROJECT» (или «Создать проект»).
  • 3
    В поле Project name введи любое название: tiktube-app или my-youtube-key
  • 4
    Нажми «CREATE» и подожди 10–15 секунд пока проект создаётся.
  • 5
    Убедись, что выбран новый проект — он должен появиться в левом верхнем углу вместо предыдущего.

Название проекта видишь только ты — называй как хочешь. Организация и Location оставляй по умолчанию.
Шаг 3

Включить YouTube Data API v3

Теперь нужно активировать нужный нам API в этом проекте.

  • 1
    В левом меню нажми «APIs & Services» → «Library» (Библиотека)
  • 2
    Откроется страница с поиском по API. В строку поиска введи: YouTube Data API v3
  • 3
    Нажми на карточку «YouTube Data API v3» в результатах.
  • 4
    На странице API нажми большую синюю кнопку «ENABLE». Подожди несколько секунд.

Шаг 4

Создать API ключ

После активации API нужно создать сам ключ доступа.

  • 1
    В левом меню нажми «APIs & Services» → «Credentials»
  • 2
    Нажми кнопку «+ CREATE CREDENTIALS» вверху страницы.
  • 3
    Из выпадающего меню выбери «API key».
  • 4
    Ключ создастся автоматически! Появится попап с твоим ключом. Скопируй его!

Твой ключ выглядит примерно вот так:

Нажми «RESTRICT KEY» — ограничь ключ только YouTube Data API v3. Это не обязательно, но безопаснее: если ключ утечёт, его нельзя будет использовать для других сервисов.

Как ограничить ключ (рекомендуется):

  • A
    В разделе «API restrictions» выбери «Restrict key»
  • B
    Из выпадающего списка выбери «YouTube Data API v3»
  • C
    Нажми «SAVE»
Шаг 5

Вставить ключ в TikTube

  • 1
    Вернись на главную страницу TikTube
  • 2
    Нажми кнопку ⚙️ в правом верхнем углу
  • 3
    Вставь скопированный ключ в поле AIzaSy...
  • 4
    Нажми «Сохранить»
  • 5
    🎉 Готово! Видео начнут загружаться.
Ключ сохраняется прямо в браузере (localStorage). Каждый раз вводить не нужно — достаточно один раз.

Лимиты и квоты

YouTube Data API v3 бесплатный, но с дневными ограничениями.

Тип запросаСтоимостьБесплатных в день
🔍 Поиск (search)100 единиц~100 поисков
▶️ Инфо о видео (videos)1 единица10 000 видео
📺 Инфо о канале1 единица10 000 запросов
📈 Тренды (mostPopular)1 единица10 000 запросов
Дневной лимит: 10 000 единиц / день Сброс квоты: каждый день в ~12:00 МСК
Для личного использования лимита более чем достаточно. Даже если смотришь весь день — вряд ли сделаешь больше 20–30 поисков.
Если лимит исчерпан — появится ошибка 403 quotaExceeded. Просто подожди до следующего дня или создай второй Google-проект с новым ключом.

Частые вопросы

API ключ бесплатный?
Да, полностью бесплатный. Карта не нужна, регистрации оплаты нет. Просто Google-аккаунт.
Ошибка "API key not valid. Please pass a valid API key"
Причины: 1) Ключ скопирован с лишним пробелом в начале или конце. 2) Для проекта не включён YouTube Data API v3. 3) Ключ ограничен по IP/домену неправильно — удали ограничения и попробуй снова.
Ошибка 403 quotaExceeded
Исчерпана дневная квота в 10 000 единиц. Подожди до следующего дня (сброс ~12:00 МСК). Или создай второй проект в Google Cloud с новым ключом.
Видео не воспроизводится, чёрный экран
Это не зависит от API ключа — ключ нужен только для поиска и метаданных. Для чёрного экрана нажми кнопку 🔄 «Прокси» на видео — приложение переключится на другой прокси-сервер. Если все прокси не работают — нажми «Открыть на YouTube».
Можно поделиться ключом с другом?
Технически да, но вы будете расходовать общую квоту. Лучше каждый создаёт свой ключ — это занимает 5 минут и полностью бесплатно.
Ссылка на видео работает без API ключа?
Да! Если кто-то прислал тебе ссылку вида ?v=VIDEO_ID — видео откроется и без API ключа. Ключ нужен только для поиска и загрузки трендов.
Мне предложили ввести платёжные данные
Это нормально — Google иногда предлагает привязать карту для «расширенного доступа». Просто закрой это предложение, оно необязательно. YouTube Data API v3 работает без карты.
